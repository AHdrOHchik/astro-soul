ПРОВАЙДЕР (6 тестов, локальный HTTP-заглушка-сервер, без сети и денег)
  1. токен кэшируется: два complete() → ровно один OAuth;
     OAuth — form-urlencoded, scope из GIGACHAT_SCOPE, RqUID = uuid4;
  2. expires_at в мс: срок 30 мин → кэш; срок 30 сек (< 60 сек запаса) → новая авторизация;
  3. 401 → сброс кэша + один повтор (2 chat-вызова, 2 OAuth);
  4. 429 → один повтор, затем LlmError(code=rate_limited), ровно 2 chat-вызова;
  5. usage 2000 токенов × 0.5 ₽/1000 = 1 ₽ (costRub округлён до 4 знаков);
  6. https без GIGACHAT_CA_BUNDLE → LlmError(code=config),
     текст содержит «проверь GIGACHAT_CA_BUNDLE»; TLS-проверка не отключается.
