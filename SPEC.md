# SPEC — что строим

Telegram Mini App: пользователь вводит дату, время и место рождения → получает натальную карту (Swiss Ephemeris) и персональный разбор из 6 глав, написанный LLM по рассчитанным фактам. Ежедневный прогноз приходит в бот.

Цель первой версии: от открытия до оплаты ≤ 3 минуты, возврат на следующий день.

Монетизация — Telegram Stars (XTR): подписка и разовые разборы. Цены и правила платежей — `payments.md`.

Аудитория: RU, 18+, женщины 22–40.

## Сценарии

**1. Онбординг и карта.** Приветствие с дисклеймером (18+, развлекательный контент) → дата → время («точно» / «примерно» / «не знаю») → место рождения (поиск города) → карта: колесо, Солнце/Луна/Асцендент, тизер разбора, «поделиться». При неизвестном времени карта строится, дома и Асцендент помечены как нерассчитанные.

**2. Покупка разбора.** Тизер (3 строки + размытие) → «Открыть полностью — 149 ⭐» → оплата → экран «готовим» с прогрессом → через 30–90 сек пуш и готовый разбор (6 глав + PDF).

**3. Подписка.** Пейволл: неделя 149 ⭐ / месяц 399 ⭐ / год 2 990 ⭐. После оплаты полный прогноз, 5 вопросов в день, совместимость 1/мес. Отмена — в настройках Telegram. Купленный разово разбор остаётся навсегда.

**4. Ежедневный прогноз.** 08:00 по часовому поясу места рождения, пуш в бот. Бесплатно — 1–2 предложения, подписка — 3–6 + «фокус дня». Никогда не генерируется в момент запроса, только из кэша.

**5. «Спроси карту».** Вопрос по своей карте: 5/день по подписке, 1/день бесплатно. Ответ ≤ 1500 символов + блок «на чём основано». Запрещённые темы (диагнозы, смерть, гарантии денег) — мягкий отказ.

**6. Удаление данных.** Кнопка в кабинете → двойное подтверждение → удаление профиля, карт, разборов, прогнозов, вопросов. Подписка живёт до конца периода.

## Экраны (9)

| # | Экран | Главное |
|---|---|---|
| 1 | Welcome | дисклеймер виден без скролла |
| 2 | BirthDate | валидация 18+ |
| 3 | BirthTime | 3 варианта, честное предупреждение о точности |
| 4 | BirthPlace | поиск от 3 символов, часовой пояс из места |
| 5 | Chart | колесо + 3 карточки + тизер + шеринг |
| 6 | Report | оглавление, главы, PDF |
| 7 | Paywall | 3 тарифа, оплата через `openInvoice` |
| 8 | Forecast | текст, фокус, «спросить карту» |
| 9 | Settings | подписка, квоты, удаление данных, поддержка |

## Данные (Postgres)

`users`, `profiles` (дата/время/место/согласие), `charts` (jsonb + `input_hash`), `reports` (статус, главы, стоимость LLM), `forecasts` (уникально по `chart_id+date`), `asks`, `subscriptions`, `payments` (уникальный `telegram_payment_charge_id`), `entitlements` (разовые покупки), `quotas`, `events`.

Подробные поля — на усмотрение BACKEND, но: `payments.telegram_payment_charge_id` уникален, `forecasts(chart_id, date)` уникален, у `charts` есть `input_hash` для идемпотентности.

## Астро-движок (`packages/astro`)

- `calcChart(input)` — планеты, дома Плацидуса, аспекты, баланс стихий. Плюс `transitsFor(date, chart)` для прогноза.
- `llmContext(chart)` — только факты в JSON. Модель не считает, а переводит.
- `renderWheel(chart)` — SVG, поворот по Асценденту.
- Детерминизм: одинаковый вход → одинаковый JSON. `time_known=false` → дома и ASC = `null`.
- Эфемериды локально, без сети. Прототип уже есть: `astro/engine.py`.
- Swiss Ephemeris под AGPL: до покупки коммерческой лицензии работает флаг `ASTRO_ENGINE=fallback`.

## Генерация текста

Две стадии: план (6 глав × 3–5 тезисов, каждый со ссылкой на позицию карты) → главы по 400–700 слов. Ответы валидируются схемой, при невалидном JSON — один ретрай, потом `failed` + автовозврат звёзд.

Текст: «ты», без запугивания и лести, в каждом разделе ссылка на конкретную позицию карты. Запрещено: предсказания событий с датами, медицина, юридика, гарантии денег, «смерть/болезнь/развод» как утверждения.

Стоимость: разбор ≤ $0.35, прогноз ≤ $0.003 с обязательным кэшем по `(chart_id, date)`. Пишем `llm_cost_usd` на каждый вызов.

## Технические рамки

- `pnpm` монорепо: `apps/web` (React+Vite), `apps/api`, `apps/bot`, `packages/astro` (Python, pyswisseph), `packages/shared`.
- Авторизация — только валидация `initData` (HMAC-SHA256, `auth_date` ≤ 24 ч). Никаких JWT в localStorage.
- p95 API без LLM ≤ 400 мс, `POST /charts` ≤ 800 мс, разбор ≤ 120 с. Бандл фронта ≤ 350 КБ gzip.
- Rate-limit: 60 req/мин чтение, 10 req/мин мутации.
- Прогнозы генерируются ночным джобом пачкой, не в момент запроса.
- Все проверки доступа — через одну функцию `getEntitlements(userId)`.
